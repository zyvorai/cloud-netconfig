Zyvor·cloud-netconfigHyperSDK · Linux daemon

Multi-homed VMs, configured correctly.

A Rust daemon reads provider metadata, reacts to netlink, and applies routing tables and secondary addresses on multi-interface cloud instances.

DISCOVER1

Provider metadata

Azure, AWS EC2, GCP, and other clients — refresh on an interval you configure.

WATCH2

Netlink events

Link and address changes trigger re-evaluation instead of polling alone.

ROUTE3

Policy routing

Separate tables for multi-homed hosts — source-based rules, not one default gateway.

APPLY4

Interfaces & IPs

Secondary addresses and enabled NIC lists from config — unprivileged except CAP_NET_ADMIN.

OPERATE5

Local API + CLI

cloud-netconfigd and cnctl for status, interfaces, and systemd day-2 ops.
